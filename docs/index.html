🌿 生態新聞摘要器

用本地 LLM（Ollama）以串流方式摘要生態保育新聞｜期中作業

做了什麼 怎麼執行 執行結果 AI 使用說明

做了什麼

這是一個 Python 命令列小工具：輸入一篇生態保育新聞的文字檔，程式會呼叫 LLM，以串流（streaming）方式一邊產生、一邊印出 3～5 個繁體中文重點。

  • 主要功能：串流摘要——模型每產生一小段文字就立刻顯示，不用等全部完成。
  • 加分功能：結構化輸出——加上 --json，依 JSON Schema 輸出 title、key_points、topics、sentiment，並用 Pydantic 驗證格式。
  • 預設使用本地 Ollama 模型（預設 qwen2.5:14b），不需要任何 API 金鑰；若在 .env 設定雲端 OpenAI 相容 API，也可以用 --provider cloud 切換。
  • 錯誤處理：Ollama 沒開、模型沒下載、檔案不存在、雲端金鑰沒設定時，都會顯示中文說明與解決方法。
  • 使用 uv 管理 Python 環境與套件；用 GitHub Actions 自動部署本頁面到 GitHub Pages。

samples/ 資料夾中的三篇新聞（臺灣黑熊、河口濕地、珊瑚白化）都是自行撰寫的虛構範例文章，僅供測試。

怎麼執行

1. 安裝 uv

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

2. 安裝 Ollama 並下載模型

到 ollama.com/download 下載安裝，然後：

ollama pull qwen2.5:14b

預設模型 qwen2.5:14b 約 9GB，執行時大約佔用 9GB VRAM（16GB 顯示卡用掉一半多一點，不會吃滿）。較輕的電腦或沒有獨立顯示卡，可改用小模型：ollama pull llama3.2:1b（或 qwen2.5:1.5b），執行時加上 --model llama3.2:1b（或 --model qwen2.5:1.5b）。

3. 安裝套件並執行

uv sync
uv run eco-news-summary samples/01_black_bear.txt              # 串流摘要（預設 qwen2.5:14b）
uv run eco-news-summary samples/02_wetland.txt --json          # 結構化 JSON 輸出
uv run eco-news-summary samples/03_coral_reef.txt --model llama3.2:1b   # 改用小模型

4.（選用）使用雲端模型

cp .env.example .env    # 在 .env 填入 CLOUD_API_KEY 等設定
uv run eco-news-summary samples/01_black_bear.txt --provider cloud

.env 已列在 .gitignore，不會被提交到 Git。

觀察

  • 1B 小模型速度快，但偶爾會夾雜英文（例如「Taiwanese」）、格式不一致（「-」後少了空格），或把數字套錯對象（原文「多了 20 隻」指的是黑面琵鷺，不是全部鳥類）。
  • 濕地那篇的第 4 點也和原文意思不同：原文說清除外來植物讓覓食空間變大，影響休息的是道路工程。
  • 換成中文能力較好的 qwen2.5:1.5b，同一篇黑熊新聞的摘要明顯比較完整（模型：qwen2.5:1.5b）：
$ uv run eco-news-summary samples/01_black_bear.txt --model qwen2.5:1.5b
[模型] ollama / qwen2.5:1.5b
- 研究團隊在山區紅外線相機中拍到臺灣黑熊母子活動，是近年來少見的畫面。
- 黑熊出現的地點比前一年更靠近登山步道，可能與秋季青剛櫟結果量較多有關。
- 管理處提醒登山客不要在山屋或步道留下廚餘，遇到黑熊時應保持距離、慢慢後退，切勿餵食或追逐拍照。
- 保育團體呼籲民眾發現不明獸鋏時立即通報，以保護臺灣黑熊族群免受獵具誤傷。

錯誤處理：Ollama 沒有啟動時

$ uv run eco-news-summary samples/01_black_bear.txt
[模型] ollama / qwen2.5:14b

錯誤：連不到 Ollama（http://localhost:11434/v1/）。
請確認：
  1. 已安裝 Ollama：https://ollama.com/download
  2. Ollama 正在執行：另開終端機執行 `ollama serve`（或開啟 Ollama App）
  3. 已下載模型：`ollama pull qwen2.5:14b`
