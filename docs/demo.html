線上試玩

這個頁面會讓你的瀏覽器直接連到你自己電腦上的 Ollama（預設 http://localhost:11434）來產生摘要。新聞文字只會送到你自己的電腦，不會上傳到其他地方，也不需要任何 API 金鑰。

提示：第一次使用？請先展開下方的 「連線設定（老師第一次使用請看）」，完成 Ollama 設定後再按「檢查連線」。

可直接輸入其他已下載的模型名稱

載入範例： 

      


      

        連線設定（老師第一次使用請看）
        
    
          
  1. 安裝 Ollama：到 ollama.com/download 下載安裝。
    2. 
          
  2. 下載模型（在終端機執行）：
    ollama pull qwen2.5:14b
# 沒有獨立顯示卡或電腦較輕，可改用小模型，並在上面「模型」欄改成同名：
ollama pull llama3.2:1b
    3. 
          
  3. 允許這個網頁連到 Ollama：Ollama 預設會拒絕其他網站的連線，要用環境變數 OLLAMA_ORIGINS 加入本網頁的來源（目前是 ）。
            
    Windows（PowerShell）：
    
            
    setx OLLAMA_ORIGINS "https://williamchen100.github.io"
    
            
    把 williamchen100 換成 GitHub 帳號名稱。執行後，從右下角系統匣（工作列）的 Ollama 圖示按右鍵選「Quit Ollama」完全結束，再重新開啟 Ollama，設定才會生效。
    
            
    macOS（Ollama App）：
    
            
    launchctl setenv OLLAMA_ORIGINS "https://williamchen100.github.io"
    
            
    然後從選單列結束 Ollama 再重新開啟。
    
            
    Linux（或直接在終端機執行 ollama serve）：
    
            
    OLLAMA_ORIGINS="https://williamchen100.github.io" ollama serve
# 若是 systemd 服務：sudo systemctl edit ollama，加入
# [Service]
# Environment="OLLAMA_ORIGINS=https://williamchen100.github.io"
# 再執行 sudo systemctl restart ollama
    
            
    比較簡單但較不安全的做法是把值設成 *（允許任何網站連到你的 Ollama），測試完建議改回來或刪除這個設定。
    
          
    4. 
          
  4. 回到這裡按「檢查連線」，看到已安裝的模型就可以按「產生摘要」。
    5. 
        

        
瀏覽器相容性：本頁是 HTTPS，連到 http://localhost 時，Chrome、Edge、Firefox 會把 localhost 視為安全來源而允許連線；Safari 可能會封鎖，建議改用其他瀏覽器。較新版的 Chrome／Edge 第一次連線時可能會跳出「存取區域網路上的裝置」之類的權限詢問，請選擇「允許」。
