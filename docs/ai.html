AI 使用說明

本作業在開發過程中使用了 Grok Bot（對話式 AI 程式助手）協助，使用範圍如下：

  • 產生專案初版架構：pyproject.toml、src/eco_news_summary/cli.py（串流摘要、--json 結構化輸出、錯誤處理）。
  • 撰寫 GitHub Actions 工作流程 .github/workflows/pages.yml。
  • 撰寫三篇虛構的範例新聞（samples/）。
  • 撰寫 README 與本網站（HTML/CSS）的初稿。
  • 撰寫「線上試玩」頁面與 docs/app.js（瀏覽器直接呼叫本機 Ollama 的串流與 JSON 結構化輸出），並用無頭 Chrome 搭配小模型 llama3.2:1b 測試。

「執行結果」頁面中的輸出是程式實際呼叫本地模型所產生的，沒有手動編修。程式本身執行時呼叫的 LLM 是 Ollama 上的開源模型（預設 qwen2.5:14b）。
