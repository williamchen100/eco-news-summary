怎麼執行

1. 安裝 uv

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# Windows（PowerShell）
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

2. 安裝 Ollama 並下載模型

到 ollama.com/download 下載安裝，然後：

ollama pull qwen2.5:14b

預設模型 qwen2.5:14b 約 9GB，執行時大約佔用 9GB VRAM（16GB 顯示卡用掉一半多一點，不會吃滿）。較輕的電腦或沒有獨立顯示卡，可改用小模型：ollama pull llama3.2:1b（或 qwen2.5:1.5b），執行時加上 --model llama3.2:1b（或 --model qwen2.5:1.5b）。

3. 安裝套件並執行

uv sync

# 串流摘要（預設 qwen2.5:14b）
uv run eco-news-summary samples/01_black_bear.txt

# 結構化 JSON 輸出
uv run eco-news-summary samples/02_wetland.txt --json

# 改用小模型
uv run eco-news-summary samples/03_coral_reef.txt --model llama3.2:1b

4.（選用）使用雲端模型

# 複製範本後，在 .env 填入 CLOUD_API_KEY 等設定
cp .env.example .env
uv run eco-news-summary samples/01_black_bear.txt --provider cloud

.env 已列在 .gitignore，不會被提交到 Git。
